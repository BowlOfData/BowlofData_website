What Maki is

Maki is a Python framework for building multi-agent LLM applications that run wherever your models do: on your own machine, through a hosted API, or a mix of both. It takes you from a single model call to coordinated, tool-using agents without tying you to one provider.

What Maki can do

Local or hosted models

Ollama, llama.cpp, OpenAI, Anthropic, OpenRouter and in-process Hugging Face sit behind one interface. Switching a model is a one-line change.

Tool-using agents

Role-based agents with memory, step-by-step reasoning and streaming. They can call tools to read files, search the web or fetch market data.

Multi-step workflows

Chain agents with dependency ordering, retries, parallel batches and checkpoint/resume, so an interrupted run picks up where it stopped.

A checker that must approve

A task can be reviewed by a second agent before it counts as done. Rejected work is redone with the feedback, up to a limit, then fails.

Safe by default

A model can only call the tool methods a plugin explicitly allows. Writing files, transferring data and trading stay off until you switch them on.

Agents as services

Serve any agent over HTTP with one command, and call it from another process as if it were local. 16 built-in plugins are included.

Try it

With Ollama running, a first agent takes a few minutes. The package is maki-framework; you import maki.

ollama pull llama3.2
pip install maki-framework
from maki import MakiLLama
from maki.agents import Agent

agent = Agent(
    name="Reviewer",
    maki_instance=MakiLLama(model="llama3.2"),
    role="code reviewer",
)
print(agent.execute_task("Review this design: a plugin system with file access."))

The quickstart covers the rest, including how to run the same agent on a hosted model.
